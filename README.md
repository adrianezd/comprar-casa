# Comprar casa

Calculadora de los gastos de comprar vivienda en España (ITP o IVA por comunidad, AJD, notaría, registro, tasación) y de la hipoteca a tipo fijo, variable o mixto con el euríbor del día. Cuota, intereses, esfuerzo, comparativa y cuánto te puedes permitir.

Sitio: https://adrianezd.github.io/comprar-casa/

- `euribor.json` lo genera `actualizar.py` cada día laborable con GitHub Actions (media mensual del BCE y valor diario de euribor-rates.eu).
- Los tipos de ITP y AJD por comunidad están al principio de `script.js`.
